Brief Summary of Work Process

In this assignment, I learned the fundamentals of JavaScript, DOM (Document Object Model) manipulation, and event handling:
1. Object & Arithmetic (Part 1): Created a structured "userProfile" object storing various data types (string, number, boolean, array). Calculated dynamic values like current age and age in months using the "Date" object and arithmetic operators, outputting them to both the DOM and browser console.
2. Forms & Event Listeners (Part 2): Built an input form with a click event listener to dynamically capture user inputs and update the userProfile object and UI in real time.
